n this work, we evaluate two task migration strategies in a peer-to-peer volunteer computing network. In the first scenario, migration is initiated as soon as the server identifies the first available volunteer node. In contrast, the second scenario delays migration until all sub-peers have completed their assigned tasks. To reflect realistic heterogeneity, we use the GWA-T-13 Materna dataset, which provides performance traces for more than 1500 virtual machines from distributed Materna data centers in Dortmund, Germany. For both scenarios, we analyze the overall task completion time as well as the maximum execution time observed across peers. The simulation results indicate that the second strategy achieves a lower total execution time compared to the first.
